B2B insights layer — four outcome types

One spend decision, four honest answers

The model doesn't check just one metric. It checks four, at the same time, off the same frozen posterior — and any one of them can refuse to answer if the data behind it is too thin, instead of guessing.
Pipeline dollars — the total value of deals currently open and being worked, not yet won or lost. Moves fast: a good ad can create new pipeline within days.

Closed-won dollars — actual signed revenue. The number everyone really cares about, but it lags far behind pipeline — deals can take months to close.

Qualified leads — a count, not a dollar figure. How many people or companies got identified as real potential buyers. Earlier in the funnel than pipeline, about volume of interest, not value yet.

Stage transitions — also a count. How many deals moved forward a stage, like demo scheduled to proposal sent. Measures momentum, not volume or dollars.

Adstock happens once, upstream of all four outcome types — it describes how this channel's exposure lingers over time, not how any one outcome responds to it. So the same adstocked exposure number feeds all four cards below; only the saturation curve and coefficient after that point are separate per outcome.
Drag any signal-strength slider low enough and that outcome type stops answering — exactly like Pipeline did on the poster. That refusal is a feature: an honest "I don't know" instead of a confident-sounding guess.
